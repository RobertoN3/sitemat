# Nexo — site de estudos de matemática

Site estático em HTML, CSS e JavaScript. Abra `index.html` para estudar localmente.

## Publicação no Vercel

Importe o repositório no Vercel. Use o preset **Other**, a pasta raiz do repositório e nenhuma etapa de build. O arquivo `vercel.json` já define a publicação estática.

Os PDFs usados pelas páginas ficam em `output/pdf/` e devem acompanhar a publicação.
